# inventory.db — split into <25MB parts

`inventory.db` (53MB, a SQLite database generated by `tools/deep-scan.js` /
`tools/inventory-report.js`) was split into 3 parts on 2026-09-20 on this
branch (codex/production-reconcile-auth-geo) so its history could be pushed
to origin without carrying the unsplit 53MB blob. Byte-for-byte reassembly
was verified with `cmp` before the original was removed from tracking.

## To reassemble and use the database

```bash
cd .ai/inventory
cat inventory.db.aa.part inventory.db.ab.part inventory.db.ac.part > inventory.db
```

Or regenerate it fresh instead of reassembling: `node tools/deep-scan.js`
(see that script for its actual invocation/output path).
