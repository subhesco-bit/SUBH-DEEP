# inventory.db — split into <25MB parts

`inventory.db` (53MB, a SQLite database generated by `tools/deep-scan.js` /
`tools/inventory-report.js`) was split into 3 parts on 2026-09-20 per
`.ai/tasks/LARGE_FILE_SPLITTING_PLAN.md` (keep everything in git, no file
over 25MB). Byte-for-byte reassembly was verified with `cmp` before the
original was removed from tracking.

## To reassemble and use the database

```bash
cd .ai/inventory
cat inventory.db.00.part inventory.db.01.part inventory.db.02.part > inventory.db
```

Or regenerate it fresh instead of reassembling: `node tools/deep-scan.js`
(see that script for its actual invocation/output path).
