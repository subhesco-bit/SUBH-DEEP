# API-001: POST /api/v1/auth/refresh

**Phase:** 4.1 (Critical Routes)  
**Service:** authService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/auth/refresh
```

### Purpose
Refresh an expired access token using a valid refresh token. This endpoint extends user sessions without requiring re-authentication.

### Service Dependency
- `backend/src/services/dual-use/authService.js`
- Method: `refreshAccessToken(refreshToken)`

## Request Specification

### Headers
```
Content-Type: application/json
```

### Body Schema
```json
{
  "refresh_token": "string (required, JWT format)"
}
```

### Validation Rules
- `refresh_token` must be a valid JWT token
- Token must not be expired
- Token must be signed with the platform's JWT secret
- Token must have the correct issuer and audience

## Response Specification

### Success Response (200 OK)
```json
{
  "success": true,
  "data": {
    "access_token": "string (JWT)",
    "refresh_token": "string (JWT, may be rotated)",
    "token_type": "Bearer",
    "expires_in": 900,
    "user": {
      "id": "uuid",
      "email": "string",
      "role": "string",
      "permissions": ["array"]
    }
  }
}
```

### Error Responses

**400 Bad Request**
```json
{
  "success": false,
  "error": {
    "code": "INVALID_TOKEN",
    "message": "Invalid or malformed refresh token"
  }
}
```

**401 Unauthorized**
```json
{
  "success": false,
  "error": {
    "code": "TOKEN_EXPIRED",
    "message": "Refresh token has expired"
  }
}
```

**403 Forbidden**
```json
{
  "success": false,
  "error": {
    "code": "TOKEN_REVOKED",
    "message": "Refresh token has been revoked"
  }
}
```

## Authentication Requirements
- No authentication required (refresh token serves as credential)
- Rate limiting: 10 requests per minute per IP

## Security Considerations
- Refresh tokens should be stored securely (httpOnly cookies or secure storage)
- Consider rotating refresh tokens on each use
- Implement token revocation on logout
- Log all refresh attempts for security monitoring
