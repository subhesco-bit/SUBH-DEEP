## Endpoint Specification

### Method & Path
```
GET /api/v1/auth/verify
```

### Purpose
Verify the validity of an access token and return user information. Used for session validation and user state synchronization.

### Service Dependency
- `backend/src/services/dual-use/authService.js`
- Method: `verifyToken(token)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Query Parameters
None

### Validation Rules
- Authorization header must be present
- Token must be a valid JWT access token
- Token must not be expired
- Token must be signed with the platform's JWT secret

