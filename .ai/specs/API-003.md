# API-003: POST /api/v1/products/create

**Phase:** 4.1 (Critical Routes)  
**Service:** productService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/products/create
```

### Purpose
Create a new product in the catalog. Used by farmers and administrators to add agricultural products to the marketplace.

### Service Dependency
- `backend/src/services/legacy/productService.js`
- Method: `createProduct(productData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "name": "string (required, min 3 chars)",
  "description": "string (required, min 10 chars)",
  "category_id": "uuid (required)",
  "state_id": "uuid (required)",
  "unit_id": "uuid (required)",
  "base_price": "number (required, > 0)",
  "gi_status": "string (optional, enum: none, pending, approved, rejected)",
  "organic": "boolean (optional, default: false)",
  "images": ["array of image URLs"],
  "varieties": ["array of strings"],
  "seasonal_availability": ["array of strings]",
  "nutritional_info": {
    "calories": "number",
    "protein": "number",
    "carbs": "number",
    "fat": "number"
  },
  "storage_requirements": "string",
  "shelf_life_days": "number"
}
```

### Validation Rules
- User must have product creation permission
- Category, state, and unit must exist in database
- Base price must be positive
- Images must be valid URLs
- GI status must be valid enum value if provided
