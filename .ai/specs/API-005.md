# API-005: DELETE /api/v1/products/:id/delete

**Phase:** 4.1 (Critical Routes)  
**Service:** productService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
DELETE /api/v1/products/:id/delete
```

### Purpose
Delete a product from the catalog. Used by product owners and administrators to remove products. Consider soft delete for data integrity.

### Service Dependency
- `backend/src/services/legacy/productService.js`
- Method: `deleteProduct(productId)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### URL Parameters
- `id` (uuid, required): Product ID to delete

### Body Schema
None

### Validation Rules
- User must have product delete permission OR be the product creator
- Product must exist in database
- Product must not have active orders
- Product must not have existing reviews (optional policy)

## Response Specification

### Success Response (200 OK)
```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "name": "string",
    "deleted": true,
    "deleted_at": "ISO8601 datetime",
    "deleted_by": "uuid"
  }
}
```

### Error Responses

**400 Bad Request**
```json
{
  "success": false,
  "error": {
    "code": "CANNOT_DELETE",
    "message": "Product cannot be deleted due to existing orders/reviews"
  }
}
```

**401 Unauthorized**
```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Authentication required"
  }
}
```

**403 Forbidden**
```json
{
  "success": false,
  "error": {
    "code": "INSUFFICIENT_PERMISSIONS",
    "message": "User does not have permission to delete this product"
  }
}
```

**404 Not Found**
```json
{
  "success": false,
  "error": {
    "code": "PRODUCT_NOT_FOUND",
    "message": "Product not found"
  }
}
```

## Authentication Requirements
- Valid access token required
- User must have `product:delete` permission OR be product creator
- Rate limiting: 10 requests per minute per user

## Security Considerations
- Implement soft delete (set is_active = false) instead of hard delete
- Validate that user has permission to delete this specific product
- Check for active orders before allowing deletion
- Implement audit logging for product deletions
- Consider requiring confirmation for product deletion
