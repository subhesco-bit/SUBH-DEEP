## Endpoint Specification

### Method & Path
```
POST /api/v1/orders/create
```

### Purpose
Create a new order from cart items or direct product selection. This is the core order creation endpoint for the marketplace.

### Service Dependency
- `backend/src/services/legacy/orderService.js`
- Method: `createOrder(orderData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema

### Validation Rules
- User must be authenticated
- At least one item must be provided
- All products must exist and be active
- Product quantities must be positive
- Product quantities must not exceed available inventory
- Shipping and billing addresses must be valid
- Payment method must be supported
