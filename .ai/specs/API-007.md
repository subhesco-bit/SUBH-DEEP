## Endpoint Specification

### Method & Path
```
POST /api/v1/orders/:id/cancel
```

### Purpose
Cancel an existing order. Used by customers to cancel orders before shipment and by administrators for order management.

### Service Dependency
- `backend/src/services/legacy/orderService.js`
- Method: `cancelOrder(orderId, cancelData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### URL Parameters
- `id` (uuid, required): Order ID to cancel

### Body Schema
```json
{
  "reason": "string (required, min 10 chars)",
  "cancellation_type": "string (optional, enum: user_cancel, admin_cancel, system_cancel)",
  "refund_requested": "boolean (optional, default: true)"
}
```

### Validation Rules
- User must be authenticated
- User must be order owner OR have admin privileges
- Order must exist
- Order must be in cancellable state (pending, confirmed)
- Reason must be provided
- Consider refund policies based on order status
