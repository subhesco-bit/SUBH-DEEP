## Endpoint Specification

### Method & Path
```
GET /api/v1/orders/:id/track
```

### Purpose
Track the status and location of an order. Provides real-time tracking information for customers and administrators.

### Service Dependency
- `backend/src/services/legacy/orderService.js`
- Method: `trackOrder(orderId)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### URL Parameters
- `id` (uuid, required): Order ID to track

### Query Parameters
None

### Validation Rules
- User must be authenticated
- User must be order owner OR have admin privileges
- Order must exist
