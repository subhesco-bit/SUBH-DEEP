# API-009: POST /api/v1/loans/apply

**Phase:** 4.1 (Critical Routes)  
**Service:** financialService  
**Priority:** P0 - Critical

## Endpoint Specification

### Method & Path
```
POST /api/v1/loans/apply
```

### Purpose
Submit a loan application for farmers. This is the primary endpoint for agricultural loan requests in the platform.

### Service Dependency
- `backend/src/services/legacy/financialService.js`
- Method: `applyForLoan(loanData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "farmer_id": "uuid (required)",
  "amount": "number (required, > 0)",
  "interest_rate": "number (optional, will use default if not provided)",
  "term_months": "number (required, > 0)",
  "purpose": "string (required, min 10 chars)",
  "collateral_type": "string (optional)",
  "collateral_value": "number (optional, > 0)",
  "guarantor_name": "string (optional)",
  "guarantor_phone": "string (optional)",
  "supporting_documents": ["array of document URLs"],
  "crop_plan": {
    "crop_type": "string",
    "acreage": "number",
    "expected_yield": "number",
    "season": "string"
  }
}
```

### Validation Rules
- User must be authenticated
- User must have loan application permission
- Farmer must exist in database
- Loan amount must be within allowed range
- Loan term must be within allowed range
- Collateral value must be >= loan amount if collateral provided
- Guarantor information must be valid if provided
