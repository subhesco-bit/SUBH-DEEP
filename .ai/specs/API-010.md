# API-010: GET /api/v1/loans/:id/status

**Phase:** 4.1 (Critical Routes)  
**Service:** financialService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
GET /api/v1/loans/:id/status
```

### Purpose
Retrieve the current status and details of a loan application. Used by farmers to track their loan application progress.

### Service Dependency
- `backend/src/services/legacy/financialService.js`
- Method: `getLoanStatus(loanId)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### URL Parameters
- `id` (uuid, required): Loan ID to check status

### Query Parameters
None

### Validation Rules
- User must be authenticated
- User must be loan applicant OR have admin privileges
- Loan must exist in database
