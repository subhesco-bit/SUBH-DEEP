## Endpoint Specification

### Method & Path
```
POST /api/v1/emi/calculate
```

### Purpose
Calculate Equated Monthly Installment (EMI) for loan repayment. Provides amortization schedule and total interest calculations.

### Service Dependency
- `backend/src/services/legacy/financialService.js`
- Method: `calculateEMI(loanParams)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "principal_amount": "number (required, > 0)",
  "interest_rate": "number (required, annual percentage rate)",
  "tenure_months": "number (required, > 0)",
  "processing_fee": "number (optional, default: 0)",
  "prepayment_option": "boolean (optional, default: false)",
  "prepayment_penalty_rate": "number (optional, default: 0)"
}
```

### Validation Rules
- User must be authenticated
- Principal amount must be positive
- Interest rate must be positive
- Tenure must be positive and within allowed range
- Processing fee must be non-negative
- Prepayment penalty rate must be non-negative
