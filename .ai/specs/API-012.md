# API-012: POST /api/v1/payments/process

**Phase:** 4.1 (Critical Routes)  
**Service:** financialService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/payments/process
```

### Purpose
Process payment for orders, loans, or other transactions. This is the primary payment processing endpoint for the platform.

### Service Dependency
- `backend/src/services/legacy/financialService.js`
- Method: `processPayment(paymentData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "transaction_type": "string (required, enum: order, loan, subscription, wallet)",
  "transaction_id": "uuid (required)",
  "amount": "number (required, > 0)",
  "payment_method": "string (required, enum: upi, card, net_banking, wallet, cod)",
  "payment_details": {
    "upi_id": "string (optional, for UPI)",
    "card_number": "string (optional, for card)",
    "card_expiry": "string (optional, for card)",
    "card_cvv": "string (optional, for card)",
    "bank_name": "string (optional, for net banking)",
    "account_number": "string (optional, for net banking)",
    "ifsc_code": "string (optional, for net banking)",
    "wallet_provider": "string (optional, for wallet)",
    "wallet_number": "string (optional, for wallet)"
  },
  "currency": "string (optional, default: INR)",
  "description": "string (optional)",
  "metadata": "object (optional)"
}
```

### Validation Rules
- User must be authenticated
- Transaction must exist and be in payable state
- Amount must match expected amount
- Payment method must be supported
- Payment details must be valid for selected method
- Card details must be valid (if card payment)
- Bank details must be valid (if net banking)
