# API-013: POST /api/v1/shipments/create

**Phase:** 4.1 (Critical Routes)  
**Service:** logisticsService

## Endpoint Specification

### Method & Path
```
POST /api/v1/shipments/create
```

### Purpose
Create a new shipment for order fulfillment. Used by logistics team and administrators to initiate shipping processes.

### Service Dependency
- `backend/src/services/legacy/logisticsService.js`
- Method: `createShipment(shipmentData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "order_id": "uuid (required)",
  "mode_id": "uuid (required)",
  "origin_address": "string (required)",
  "destination_address": "string (required)",
  "origin_lat": "number (optional)",
  "origin_lng": "number (optional)",
  "dest_lat": "number (optional)",
  "dest_lng": "number (optional)",
  "weight_kg": "number (required, > 0)",
  "volume_cbm": "number (optional, > 0)",
  "is_perishable": "boolean (optional, default: false)",
  "temperature_requirement": "string (optional, for perishable goods)",
  "special_instructions": "string (optional)",
  "pickup_date": "ISO8601 datetime (optional)",
  "delivery_deadline": "ISO8601 datetime (optional)"
}
```

### Validation Rules
- User must be authenticated
- User must have shipment creation permission
- Order must exist and be in shippable state
- Transport mode must exist
- Weight must be positive
- Temperature requirement required if perishable
- Pickup date must be in future if provided
