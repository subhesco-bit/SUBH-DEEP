# API-014: GET /api/v1/shipments/:id/track

**Phase:** 4.1 (Critical Routes)  
**Service:** logisticsService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
GET /api/v1/shipments/:id/track
```

### Purpose
Track the real-time location and status of a shipment. Provides tracking information for customers and logistics team.

### Service Dependency
- `backend/src/services/legacy/logisticsService.js`
- Method: `trackShipment(shipmentId)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### URL Parameters
- `id` (uuid, required): Shipment ID to track

### Query Parameters
None

### Validation Rules
- User must be authenticated
- User must be order owner OR have logistics permissions
- Shipment must exist in database

- Valid access token required
- User must be order owner OR have `shipment:view` permission
- Rate limiting: 60 requests per minute per user
