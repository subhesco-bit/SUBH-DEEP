## Endpoint Specification

### Method & Path
```
GET /api/v1/insurance/policies
```

### Purpose
Retrieve insurance policies for a user or farmer. This endpoint provides access to policy information for customers and administrators.

### Service Dependency
- `backend/src/services/legacy/insuranceService.js`
- Method: `getUserPolicies(userId, filters)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Query Parameters
```json
{
  "user_id": "uuid (optional, defaults to current user)",
  "farmer_id": "uuid (optional)",
  "status": "string (optional, enum: active, expired, pending, cancelled)",
  "policy_type": "string (optional)",
  "master_policy_id": "uuid (optional)",
  "page": "number (optional, default: 1)",
  "limit": "number (optional, default: 20)",
  "sort_by": "string (optional, default: created_at)",
  "sort_order": "string (optional, default: DESC)"

```

### Validation Rules
- User must be authenticated
- User can view own policies or must have admin permissions
- Pagination parameters must be valid
- Status must be valid enum value if provided
