# API-016: POST /api/v1/insurance/apply

**Phase:** 4.1 (Critical Routes)  
**Service:** insuranceService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/insurance/apply
```

### Purpose
Apply for a new insurance policy. This is the primary endpoint for farmers and customers to request insurance coverage.

### Service Dependency
- `backend/src/services/legacy/insuranceService.js`
- Method: `createPolicy(policyData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "user_id": "uuid (optional, defaults to current user)",
  "farmer_id": "uuid (required)",
  "product_id": "uuid (required)",
  "master_policy_id": "uuid (optional)",
  "coverage_amount": "number (required, > 0)",
  "policy_start_date": "ISO8601 datetime (required)",
  "policy_end_date": "ISO8601 datetime (required)",
  "insurer_name": "string (optional)",
  "insurer_policy_number": "string (optional)",
  "beneficiaries": [
    {
      "name": "string (required)",
      "relationship": "string (required)",
      "contact": "string (required)"
    }
  ],
  "supporting_documents": ["array of document URLs"],
  "additional_info": "string (optional)"
}
```

### Validation Rules
- User must be authenticated
- Farmer must exist in database
- Product must exist and be insurable
- Coverage amount must be within allowed range
- Policy dates must be valid (end date > start date)
- At least one beneficiary must be provided
- Beneficiary information must be complete
