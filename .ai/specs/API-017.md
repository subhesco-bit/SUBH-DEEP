# API-017: POST /api/v1/insurance/claims/file

**Phase:** 4.1 (Critical Routes)  
**Service:** insuranceService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/insurance/claims/file
```

### Purpose
File an insurance claim for a policy. This is the primary endpoint for policyholders to submit claims for damages or losses.

### Service Dependency
- `backend/src/services/legacy/insuranceService.js`
- Method: `fileClaim(claimData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "policy_id": "uuid (required)",
  "claim_type": "string (required, enum: crop_damage, natural_disaster, theft, accident, other)",
  "incident_date": "ISO8601 datetime (required)",
  "incident_location": {
    "address": "string (required)",
    "lat": "number (optional)",
    "lng": "number (optional)"
  },
  "estimated_loss": "number (required, > 0)",
  "description": "string (required, min 20 chars)",
  "evidence_documents": ["array of document URLs (required)"],
  "witness_details": [
    {
      "name": "string",
      "contact": "string",
      "statement": "string"
    }
  ],
  "police_report_filed": "boolean (optional, default: false)",
  "police_report_number": "string (optional, if police_report_filed is true)",
  "additional_info": "string (optional)"
}
```

### Validation Rules
- User must be authenticated
- Policy must exist and belong to user or user must have admin permissions
- Policy must be active on incident date
- Incident date must be within policy coverage period
- At least one evidence document must be provided
- Estimated loss must be positive and reasonable
- Police report number required if police report filed

## Authentication Requirements
- Valid access token required
- User must be policy holder OR have `insurance:claim` permission
- Rate limiting: 5 requests per minute per user
