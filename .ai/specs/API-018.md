# API-018: POST /api/v1/mfa/setup

**Phase:** 4.1 (Critical Routes)  
**Service:** mfaService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/mfa/setup
```

### Purpose
Set up multi-factor authentication for a user account. This endpoint initiates the MFA enrollment process and generates setup credentials.

### Service Dependency
- `backend/src/services/dual-use/mfaService.js`
- Method: `setupMFA(userId, method)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "method": "string (required, enum: totp, sms)",
  "phone_number": "string (required if method is sms, format: +91XXXXXXXXXX)"
}
```

### Validation Rules
- User must be authenticated
- MFA method must be supported
- Phone number must be valid if SMS method selected
- User must not already have MFA enabled

## Response Specification

### Success Response (200 OK)
```json
{
  "success": true,
  "data": {
    "setup_token": "string (temporary token for verification)",
    "method": "string",
    "qr_code": "string (data URL for TOTP method)",
    "secret": "string (base32 encoded secret for TOTP)",
    "backup_codes": ["array of backup codes"],
    "sms_sent": "boolean (for SMS method)",
    "expires_at": "ISO8601 datetime"
  }
}
```

### Error Responses

**400 Bad Request**
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid MFA setup data",
    "details": {
      "field": "validation_error_message"
    }
  }
}
```

**400 Bad Request (Already Enabled)**
```json
{
  "success": false,
  "error": {
    "code": "MFA_ALREADY_ENABLED",
    "message": "MFA is already enabled for this account"
  }
}
```

**401 Unauthorized**
```json
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Authentication required"
  }
}
```

**422 Unprocessable Entity**
```json
{
  "success": false,
  "error": {
    "code": "SMS_SEND_FAILED",
    "message": "Failed to send SMS verification code"
  }
}
```

- Rate limiting: 5 requests per minute per user
