## Endpoint Specification

### Method & Path
```
POST /api/v1/mfa/verify
```

### Purpose
Verify multi-factor authentication code during login or MFA setup. This endpoint validates TOTP codes or SMS verification codes.

### Service Dependency
- `backend/src/services/dual-use/mfaService.js`
- Method: `verifyMFA(userId, code, method)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "code": "string (required, 6-digit code)",
  "method": "string (required, enum: totp, sms, backup)",
  "setup_token": "string (optional, for MFA setup verification)"
}
```

### Validation Rules
- User must be authenticated
- Code must be 6 digits
- Method must be valid
- Setup token required if completing MFA setup
- Rate limiting should be enforced (max 5 attempts per minute)

## Authentication Requirements
- Valid access token required
- Rate limiting: 5 attempts per minute per user

- Implement exponential backoff for failed attempts
- Lock account after too many failed attempts
- Use time-safe comparison for code verification
- Rate limit to prevent brute force attacks
- Log all verification attempts (success and failure)
- Invalidate setup token after successful verification
