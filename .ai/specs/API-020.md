# API-020: POST /api/v1/data/export

**Phase:** 4.1 (Critical Routes)  
**Service:** gdprService  
**Priority:** P0 - Critical  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/data/export
```

### Purpose
Export user data in compliance with GDPR data portability requirements. This endpoint allows users to request a copy of all their personal data.

### Service Dependency
- `backend/src/services/dual-use/gdprService.js`
- Method: `exportUserData(userId, exportOptions)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "export_format": "string (optional, enum: json, csv, pdf, default: json)",
  "data_categories": ["array of strings (optional)"],
  "include_deleted": "boolean (optional, default: false)",
  "date_range": {
    "start_date": "ISO8601 datetime (optional)",
    "end_date": "ISO8601 datetime (optional)"
  },
  "compression": "boolean (optional, default: true)"
}
```

### Validation Rules
- User must be authenticated
- User can only export their own data (unless admin)
- Export format must be supported
- Data categories must be valid if provided
- Date range must be valid if provided

### Available Data Categories
- `profile` - User profile information
- `orders` - Order history
- `payments` - Payment history
- `loans` - Loan applications and status
- `insurance` - Insurance policies and claims
- `shipments` - Shipment history
- `consents` - GDPR consent records
- `activity` - User activity logs
- `communications` - Communication history

## Authentication Requirements
- Valid access token required
- User can export own data OR have `data:export` permission
- Rate limiting: 1 export request per day per user

## Security Considerations

- Implement data retention policies for export files
- Encrypt export files at rest
- Use expiring download tokens
- Implement export rate limiting
- Log all export requests for audit
- Sanitize sensitive data before export
- Consider implementing admin approval for large exports
