## Endpoint Specification

### Method & Path
```
POST /api/v1/ai/copilot/chat
```

### Purpose
Send a message to the AI copilot for intelligent assistance with agricultural decisions, market analysis, or platform navigation.

### Service Dependency
- `backend/src/services/legacy/aiCopilotService.js`
- Method: `processChatMessage(userId, message, context)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "message": "string (required, min 1 char)",
  "context": {
    "module": "string (optional, enum: marketplace, finance, logistics, insurance, general)",
    "farmer_id": "uuid (optional)",
    "crop_id": "uuid (optional)",
    "order_id": "uuid (optional)",
    "session_id": "string (optional, for conversation continuity)"
  },
  "preferences": {
    "language": "string (optional, default: en)",
    "response_format": "string (optional, enum: text, structured, both)",
    "include_recommendations": "boolean (optional, default: true)"
  }
}
```

### Validation Rules
- User must be authenticated
- Message must not be empty
- Context IDs must be valid if provided
- Language must be supported if provided
