# API-024: GET /api/v1/analytics/dashboard

**Phase:** 4.2 (Major Routes)  
**Service:** analyticsService  
**Priority:** P1 - High

## Endpoint Specification

### Method & Path
```
GET /api/v1/analytics/dashboard
```

### Purpose
Retrieve comprehensive analytics dashboard data for platform overview, including key metrics, trends, and performance indicators.

### Service Dependency
- `backend/src/services/legacy/analyticsService.js`
- Method: `getDashboardData(userId, filters)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Query Parameters
```json
{
  "time_range": "string (optional, enum: today, week, month, quarter, year, default: month)",
  "entity_type": "string (optional, enum: platform, farmer, buyer, admin)",
  "entity_id": "uuid (optional)",
  "metrics": ["array of strings (optional)"],
  "include_forecasts": "boolean (optional, default: false)"
}
```

### Validation Rules
- User must be authenticated
- User must have permission to view requested entity analytics
- Time range must be valid if provided
- Entity must exist if entity_id provided

- Valid access token required
- User must have `analytics:view` permission for requested entity
- Rate limiting: 30 requests per minute per user
