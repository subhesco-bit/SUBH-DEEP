# API-025: POST /api/v1/analytics/report

**Phase:** 4.2 (Major Routes)  
**Service:** analyticsService  
**Priority:** P1 - High  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/analytics/report
```

### Purpose
Generate custom analytics reports with specified parameters, filters, and output formats. Supports scheduled and on-demand report generation.

### Service Dependency
- `backend/src/services/legacy/analyticsService.js`
- Method: `generateReport(userId, reportConfig)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "report_type": "string (required, enum: sales, inventory, financial, user_activity, performance)",
  "time_range": {
    "start_date": "ISO8601 datetime (required)",
    "end_date": "ISO8601 datetime (required)"
  },
  "filters": {
    "region": "string (optional)",
    "category": "string (optional)",
    "user_type": "string (optional)",
    "status": "string (optional)"
  },
  "output_format": "string (optional, enum: json, csv, pdf, xlsx, default: json)",
  "include_charts": "boolean (optional, default: true)",
  "include_raw_data": "boolean (optional, default: false)",
  "schedule": {
    "enabled": "boolean (optional, default: false)",
    "frequency": "string (optional, enum: daily, weekly, monthly)",
    "recipients": ["array of email addresses (optional)"]
  }
}
```

### Validation Rules
- User must be authenticated
- User must have permission to generate requested report type
- Date range must be valid (end date > start date)
- Date range should not exceed maximum allowed period
- Output format must be supported
