## Endpoint Specification

### Method & Path
```
POST /api/v1/blockchain/verify
```

### Purpose
Verify product authenticity and traceability using blockchain technology. Provides immutable proof of product origin, handling, and quality.

### Service Dependency
- `backend/src/services/legacy/blockchainVerificationService.js`
- Method: `verifyProduct(productId, verificationData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "product_id": "uuid (required)",
  "verification_type": "string (required, enum: authenticity, quality, traceability, full)",
  "blockchain_reference": "string (optional, transaction hash)",
  "include_history": "boolean (optional, default: true)",
  "include_certificates": "boolean (optional, default: true)"
}
```

### Validation Rules
- User must be authenticated
- Product must exist in database
- Verification type must be valid
- Blockchain reference must be valid if provided
