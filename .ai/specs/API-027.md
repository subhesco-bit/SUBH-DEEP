# API-027: POST /api/v1/blockchain/register

**Phase:** 4.2 (Major Routes)  
**Service:** blockchainVerificationService  
**Priority:** P1 - High  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/blockchain/register
```

### Purpose
Register a product on the blockchain for traceability and authenticity verification. Creates an immutable record of product origin and handling.

### Service Dependency
- `backend/src/services/legacy/blockchainVerificationService.js`
- Method: `registerProduct(productId, registrationData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "product_id": "uuid (required)",
  "origin_data": {
    "farm_id": "uuid (required)",
    "farm_name": "string (required)",
    "location": {
      "address": "string (required)",
      "lat": "number (optional)",
      "lng": "number (optional)"
    },
    "harvest_date": "ISO8601 datetime (required)",
    "cultivation_method": "string (optional, enum: organic, conventional, hybrid)"
  },
  "quality_data": {
    "grade": "string (optional)",
    "certifications": ["array of strings (optional)"],
    "test_results": {
      "pesticide_residue": "string (optional)",
      "moisture_content": "number (optional)",
      "other_parameters": "object (optional)"
    }
  },
  "supply_chain_data": {
    "handlers": ["array of handler information"],
    "transports": ["array of transport information"]
  }
}
```

### Validation Rules
- User must be authenticated
- User must have blockchain registration permission
- Product must exist and belong to user
- Origin data must be complete
- Farm must exist in database
