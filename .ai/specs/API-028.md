# API-028: POST /api/v1/iot/devices/register

**Phase:** 4.2 (Major Routes)  
**Service:** iotIntegrationService  
**Priority:** P1 - High  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/iot/devices/register
```

### Purpose
Register a new IoT device for agricultural monitoring. Connects sensors and smart devices to the platform for real-time data collection.

### Service Dependency
- `backend/src/services/legacy/iotIntegrationService.js`
- Method: `registerDevice(deviceData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "device_type": "string (required, enum: soil_sensor, weather_station, irrigation_controller, livestock_tracker, storage_monitor)",
  "device_name": "string (required)",
  "manufacturer": "string (required)",
  "model": "string (required)",
  "serial_number": "string (required)",
  "firmware_version": "string (optional)",
  "location": {
    "farm_id": "uuid (required)",
    "field_id": "uuid (optional)",
    "coordinates": {
      "lat": "number (optional)",
      "lng": "number (optional)"
    },
    "installation_date": "ISO8601 datetime (optional)"
  },
  "capabilities": {
    "sensors": ["array of sensor types"],
    "actuators": ["array of actuator types"],
    "communication_protocol": "string (optional, enum: mqtt, http, coap, lora)",
    "data_frequency": "number (optional, seconds)"
  },
  "configuration": {
    "sampling_rate": "number (optional)",
    "alert_thresholds": "object (optional)",
    "calibration_data": "object (optional)"
  }
}
```

### Validation Rules
- User must be authenticated
- User must have IoT device registration permission
- Device type must be supported
- Serial number must be unique
- Farm must exist and belong to user
