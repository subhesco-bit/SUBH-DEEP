# API-029: GET /api/v1/iot/devices/:id/data

**Phase:** 4.2 (Major Routes)  
**Service:** iotIntegrationService  
**Priority:** P1 - High  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
GET /api/v1/iot/devices/:id/data
```

### Purpose
Retrieve real-time and historical data from IoT devices. Provides sensor readings, device status, and telemetry information.

### Service Dependency
- `backend/src/services/legacy/iotIntegrationService.js`
- Method: `getDeviceData(deviceId, filters)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### URL Parameters
- `id` (uuid, required): Device ID to retrieve data from

### Query Parameters
```json
{
  "data_type": "string (optional, enum: realtime, historical, both, default: both)",
  "start_time": "ISO8601 datetime (optional, for historical data)",
  "end_time": "ISO8601 datetime (optional, for historical data)",
  "aggregation": "string (optional, enum: raw, hourly, daily, weekly, default: raw)",
  "sensors": ["array of sensor types (optional)"],
  "limit": "number (optional, default: 1000)"
}
```

### Validation Rules
- User must be authenticated
- User must have permission to access this device
- Device must exist
- Date range must be valid if provided
- Aggregation must be valid if provided
