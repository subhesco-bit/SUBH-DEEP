## Endpoint Specification

### Method & Path
```
POST /api/v1/agriculture/crop-plan
```

### Purpose
Create a crop plan for agricultural cultivation. Provides AI-powered recommendations for crop selection, timing, and resource allocation.

### Validation Rules
- User must be authenticated
- User must have crop planning permission
- Farmer must exist
- Land record must exist and belong to farmer
- At least one crop must be specified
- Total acreage must not exceed land record size
