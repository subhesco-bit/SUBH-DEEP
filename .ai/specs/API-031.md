# API-031: GET /api/v1/agriculture/weather

**Phase:** 4.2 (Major Routes)

**Priority:** P1 - High

## Endpoint Specification

### Method & Path
```
GET /api/v1/agriculture/weather
```

### Purpose
Retrieve weather information and forecasts for agricultural planning. Provides current conditions, forecasts, and historical weather data.

### Service Dependency
- `backend/src/services/legacy/climateMonitoringService.js`
- Method: `getWeatherData(location, forecastDays)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Query Parameters
```json
{
  "location": "string (required, can be city name, coordinates, or farm_id)",
  "forecast_days": "number (optional, default: 7, max: 14)",
  "include_historical": "boolean (optional, default: false)",
  "historical_days": "number (optional, default: 30)",
  "units": "string (optional, enum: metric, imperial, default: metric)"
}
```

### Validation Rules
- User must be authenticated
- Location must be provided and valid
- Forecast days must be between 1 and 14
- Historical days must be reasonable if provided
