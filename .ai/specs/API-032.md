## Endpoint Specification

### Method & Path
```
POST /api/v1/agriculture/advisory
```

### Purpose
Request AI-powered agricultural advisory based on current conditions, weather forecasts, and crop requirements. Provides actionable recommendations for farmers.

### Service Dependency
- `backend/src/services/legacy/climateAdvisoryService.js`
- Method: `generateAdvisory(farmerId, advisoryRequest)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "farmer_id": "uuid (required)",
  "crop_id": "uuid (optional)",
  "location": {
    "farm_id": "uuid (optional)",
    "coordinates": {
      "lat": "number (optional)",

    },

  "time_horizon": "string (optional, enum: immediate, week, month, season, default: week)",
  "current_conditions": {
    "growth_stage": "string (optional)",
    "soil_moisture": "number (optional)",
    "plant_health": "string (optional)",
    "observed_issues": ["array of strings (optional)"]
  },
  "preferences": {
    "organic_only": "boolean (optional, default: false)",
    "budget_conscious": "boolean (optional, default: true)",
    "risk_tolerance": "string (optional, enum: low, medium, high)",
    "language": "string (optional, default: en)"
  }
}
```

### Validation Rules
- User must be authenticated
- User must have advisory access permission
- Farmer must exist
- Location must be provided (farm_id, coordinates, or address)
- Advisory type must be valid
