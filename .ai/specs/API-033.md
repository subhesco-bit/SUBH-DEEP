# API-033: POST /api/v1/marketplace/listing

**Phase:** 4.2 (Major Routes)  
**Service:** marketplaceService  
**Priority:** P1 - High  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/marketplace/listing
```

### Purpose
Create a new marketplace listing for agricultural products. Allows farmers and sellers to list products for sale on the platform.

### Service Dependency
- `backend/src/services/legacy/marketplaceService.js`
- Method: `createListing(listingData)`

## Request Specification

### Headers
```

Content-Type: application/json
```

### Body Schema

### Validation Rules
- User must be authenticated
- User must have marketplace listing permission
- Product must exist and belong to seller
- Quantity must be positive
- Price must be positive
- Availability dates must be valid
- Auction settings required if listing type is auction
