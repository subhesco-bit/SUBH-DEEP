# API-035: POST /api/v1/marketplace/inquiry

**Phase:** 4.2 (Major Routes)

## Endpoint Specification

### Method & Path
```
POST /api/v1/marketplace/inquiry
```

### Purpose
Send an inquiry to a seller about a marketplace listing. Facilitates buyer-seller communication before purchase.

### Service Dependency
- `backend/src/services/legacy/marketplaceService.js`
- Method: `sendInquiry(listingId, inquiryData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "listing_id": "uuid (required)",
  "buyer_id": "uuid (required)",
  "inquiry_type": "string (required, enum: price_negotiation, product_details, availability, delivery, general)",
  "message": "string (required, min 10 chars)",
  "proposed_quantity": "number (optional)",
  "proposed_price": "number (optional)",
  "contact_preferences": {
    "preferred_method": "string (optional, enum: email, phone, platform, default: platform)",
    "phone_number": "string (optional)",
    "available_times": ["array of time ranges (optional)"]
  }
}
```

### Validation Rules
- User must be authenticated
- User must have inquiry permission
- Listing must exist and be active
- Buyer cannot be the seller
- Message must be meaningful length
- Proposed quantity must be positive if provided
