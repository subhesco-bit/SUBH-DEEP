# API-036: POST /api/v1/cooperative/join

**Phase:** 4.2 (Major Routes)  
**Service:** cooperativeShareService  
**Priority:** P1 - High  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/cooperative/join
```

### Purpose
Submit an application to join an agricultural cooperative. Allows farmers to apply for membership in farming cooperatives.

### Service Dependency
- `backend/src/services/legacy/cooperativeShareService.js`
- Method: `applyForMembership(cooperativeId, applicationData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "cooperative_id": "uuid (required)",
  "farmer_id": "uuid (required)",
  "membership_type": "string (required, enum: regular, associate, honorary)",
  "share_quantity": "number (required, > 0)",
  "investment_amount": "number (required, > 0)",
  "farm_details": {
    "total_land_acres": "number (required)",
    "primary_crops": ["array of strings (required)"],
    "farming_methods": ["array of strings (optional)"],
    "certifications": ["array of strings (optional)"]
  },
  "business_interests": ["array of strings (optional)"],
  "references": [
    {
      "name": "string (required)",
      "contact": "string (required)",
      "relationship": "string (required)"
    }
  ],
  "agreement_terms": "boolean (required, must be true)"
}
```

### Validation Rules
- User must be authenticated
- User must have cooperative application permission
- Cooperative must exist and be accepting members
- Farmer must exist
- Share quantity must meet minimum requirements
- Investment amount must match share quantity
- Agreement terms must be accepted
