## Endpoint Specification

### Method & Path
```
GET /api/v1/cooperative/shares
```

### Purpose
Retrieve cooperative share information and ownership details. Provides share valuation, dividend information, and ownership records.

### Service Dependency
- `backend/src/services/legacy/cooperativeShareService.js`
- Method: `getShareInformation(cooperativeId, filters)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Query Parameters
```json
{
  "cooperative_id": "uuid (required)",
  "farmer_id": "uuid (optional, for specific farmer shares)",
  "include_valuation": "boolean (optional, default: true)",
  "include_dividends": "boolean (optional, default: true)",
  "include_history": "boolean (optional, default: false)",
  "year": "number (optional, for dividend history)"
}
```

### Validation Rules
- User must be authenticated
- User must have permission to view cooperative shares
- Cooperative must exist
- Year must be valid if provided
