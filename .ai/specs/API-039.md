# API-039: POST /api/v1/enterprise/sync

**Phase:** 4.2 (Major Routes)  
**Service:** enterpriseIntegrationService  
**Priority:** P1 - High  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/enterprise/sync
```

### Purpose
Trigger manual data synchronization with enterprise ERP system. Forces immediate sync of specified data types.

### Service Dependency
- `backend/src/services/legacy/enterpriseIntegrationService.js`
- Method: `triggerSync(integrationId, syncOptions)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "integration_id": "uuid (required)",
  "sync_type": "string (required, enum: full, incremental, specific_data)",
  "data_types": ["array of strings (optional, defaults to configured types)"],
  "direction": "string (optional, enum: inbound, outbound, bidirectional, defaults to configured)",
  "force": "boolean (optional, default: false)",
  "dry_run": "boolean (optional, default: false)",
  "notification_preferences": {
    "on_completion": "boolean (optional, default: true)",
    "on_error": "boolean (optional, default: true),
    "email_recipients": ["array of email addresses (optional)"]
  }
}
```

### Validation Rules
- User must be authenticated
- User must have enterprise sync permission
- Integration must exist and be active
- Data types must be valid if provided
- Force sync requires admin permission

## Example cURL Commands

### Trigger incremental sync

  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \
