## Endpoint Specification

### Method & Path
```
POST /api/v1/voice/command
```

### Purpose
Process voice commands for platform interaction. Allows users to control the platform through voice commands in regional languages.

### Service Dependency
- `backend/src/services/legacy/voiceAIService.js`
- Method: `processVoiceCommand(audioData, context)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: multipart/form-data
```

### Body (multipart/form-data)
- `audio_file` (file, required): Audio file containing voice command
- `language` (string, optional): Language code (default: auto-detect)
- `context` (string, optional): JSON string with context information
- `format` (string, optional): Audio format (default: auto-detect)

### Validation Rules
- User must be authenticated
- Audio file must be valid format
- Audio file must not exceed size limit
- Language must be supported if provided
