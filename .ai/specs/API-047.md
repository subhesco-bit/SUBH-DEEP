## Endpoint Specification

### Method & Path
```
POST /api/v1/voice/synthesis
```

### Purpose
Convert text to speech for accessibility and voice responses. Generates audio from text in multiple languages and voices.

### Service Dependency
- `backend/src/services/legacy/voiceAIService.js`
- Method: `synthesizeSpeech(text, options)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "text": "string (required, min 1 char)",
  "language": "string (optional, default: en)",
  "voice": "string (optional, default: default)",
  "speed": "number (optional, default: 1.0, range: 0.5-2.0)",
  "pitch": "number (optional, default: 1.0, range: 0.5-2.0)",
  "output_format": "string (optional, enum: mp3, wav, ogg, default: mp3)"
}
```

### Validation Rules
- User must be authenticated
- Text must not be empty
- Text must not exceed maximum length
- Language must be supported if provided
- Speed and pitch must be within valid ranges
