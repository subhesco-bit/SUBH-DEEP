# API-048: POST /api/v1/analytics/custom

**Phase:** 4.3 (Optional Routes)

## Endpoint Specification

### Method & Path
```
POST /api/v1/analytics/custom
```

### Purpose
Execute custom analytics queries for specialized reporting and analysis. Allows users to run custom SQL-like queries on platform data.

### Service Dependency
- `backend/src/services/legacy/analyticsService.js`
- Method: `executeCustomQuery(queryConfig)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "query_type": "string (required, enum: aggregation, trend, comparison, cohort)",
  "data_source": "string (required, enum: orders, products, users, inventory, financial)",
  "metrics": ["array of strings (required)"],
  "dimensions": ["array of strings (optional)"],
  "filters": {
    "time_range": {
      "start_date": "ISO8601 datetime (optional)",
      "end_date": "ISO8601 datetime (optional)"
    },
    "conditions": "object (optional)"
  },
  "grouping": {
    "by": "string (optional)",
    "time_interval": "string (optional, enum: day, week, month, quarter, year)"
  },
  "calculations": {
    "formulas": ["array of strings (optional)"],
    "custom_fields": "object (optional)"
  }
}
```

### Validation Rules
- User must be authenticated
- User must have custom analytics permission
- Query type must be valid
- Data source must be accessible
- Metrics must be valid for data source
