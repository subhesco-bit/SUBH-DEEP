## Endpoint Specification

### Method & Path
```
POST /api/v1/blockchain/audit
```

### Purpose
Perform blockchain audit trail verification for product traceability. Provides complete history of blockchain transactions for compliance and transparency.

### Service Dependency
- `backend/src/services/legacy/blockchainVerificationService.js`
- Method: `auditTrail(productId, auditOptions)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "product_id": "uuid (required)",
  "audit_type": "string (required, enum: full, supply_chain, quality, ownership)",
  "include_raw_data": "boolean (optional, default: false)",
  "verify_signatures": "boolean (optional, default: true)",
  "depth": "number (optional, default: 10, max: 100)"
}
```

### Validation Rules
- User must be authenticated
- User must have blockchain audit permission
- Product must exist
- Audit type must be valid
- Depth must be reasonable if provided
