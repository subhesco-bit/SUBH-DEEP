## Endpoint Specification

### Method & Path
```
POST /api/v1/iot/analytics
```

### Purpose
Perform advanced analytics on IoT sensor data. Provides insights, patterns, and predictions from agricultural sensor networks.

### Service Dependency

### Headers
```

Content-Type: application/json
```

### Body Schema
```json
{
  "device_ids": ["array of uuids (required)"],
  "analysis_type": "string (required, enum: trend, anomaly, prediction, correlation, aggregation)",
  "time_range": {
    "start_time": "ISO8601 datetime (required)",
    "end_time": "ISO8601 datetime (required)"
  },
  "parameters": {
    "sensors": ["array of sensor types (optional)"],
    "aggregation_interval": "string (optional, enum: raw, hourly, daily, weekly)",
    "thresholds": {
      "min": "number (optional)",

    "comparison_baseline": "string (optional, enum: previous_period, same_period_last_year)"
  }
}
```

### Validation Rules
- User must be authenticated
- User must have IoT analytics permission
- Device IDs must be valid and accessible
- Time range must be valid
- Analysis type must be supported
