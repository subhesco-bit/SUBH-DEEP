## Endpoint Specification

### Method & Path
```
POST /api/v1/marketplace/auction/bid
```

### Purpose
Place a bid on an auction listing. Handles bidding logic, validation, and automatic bid management.

### Service Dependency
- `backend/src/services/legacy/marketplaceService.js`
- Method: `placeBid(listingId, bidData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "listing_id": "uuid (required)",
  "bidder_id": "uuid (required)",
  "bid_amount": "number (required, > 0)",
  "quantity": "number (optional, default: 1)",
  "auto_bid": "boolean (optional, default: false)",
  "max_bid_amount": "number (optional, required if auto_bid is true)",
  "terms_accepted": "boolean (required, must be true)"
}
```

### Validation Rules
- User must be authenticated
- User must have bidding permission
- Listing must exist and be an active auction
- Bid amount must be higher than current bid
- Bidder cannot be the seller
- Terms must be accepted
