## Endpoint Specification

### Method & Path
```
GET /api/v1/marketplace/auction/:id/bids
```

### Purpose
Retrieve bid history for an auction listing. Provides transparency on bidding activity and current auction status.

### Service Dependency
- `backend/src/services/legacy/marketplaceService.js`
- Method: `getAuctionBids(listingId, filters)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### URL Parameters
- `id` (uuid, required): Auction listing ID

### Query Parameters
```json
{
  "include_anonymous": "boolean (optional, default: false)",
  "limit": "number (optional, default: 20)",
  "offset": "number (optional, default: 0)"
}
```

### Validation Rules
- User must be authenticated
- Listing must exist and be an auction
- Pagination parameters must be valid
