## Endpoint Specification

### Method & Path
```
POST /api/v1/escrow/create
```

### Purpose
Create an escrow arrangement for secure transactions. Holds funds in escrow until transaction conditions are met.

### Service Dependency
- `backend/src/services/legacy/escrowService.js`
- Method: `createEscrow(escrowData)`

### Validation Rules
- User must be authenticated
- User must have escrow creation permission
- Transaction must exist
- Buyer and seller must be different
- Amount must be positive
- At least one release condition must be specified
