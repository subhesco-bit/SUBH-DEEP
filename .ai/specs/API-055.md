## Endpoint Specification

### Method & Path
```
POST /api/v1/escrow/release
```

### Purpose
Release funds from escrow to seller when conditions are met. Handles fund transfer and condition verification.

### Service Dependency
- `backend/src/services/legacy/escrowService.js`
- Method: `releaseEscrow(escrowId, releaseData)`

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "escrow_id": "uuid (required)",
  "release_type": "string (required, enum: full, partial),
  "release_amount": "number (optional, required for partial release)",
  "reason": "string (required)",
  "evidence": {
    "documents": ["array of document URLs (optional)"],
    "verification_code": "string (optional)",
    "notes": "string (optional)"
  },
  "released_by": "string (required, enum: buyer, seller, platform, auto)"
}
```

### Validation Rules
- User must be authenticated
- User must have escrow release permission
- Escrow must exist and be in releasable state
- Release amount must be valid for partial release
- Evidence must be provided if required
