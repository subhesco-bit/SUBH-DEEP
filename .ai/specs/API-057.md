## Endpoint Specification

### Method & Path
```
POST /api/v1/credit-score/evaluate
```

### Purpose
Evaluate and calculate credit score for farmers based on financial history, agricultural performance, and platform activity.

### Service Dependency
- `backend/src/services/legacy/financialService.js`


### Body Schema
```json
{

  "evaluation_type": "string (required, enum: loan_application, periodic_review, comprehensive)",
  "include_factors": ["array of strings (optional)"],
```

### Validation Rules
- User must be authenticated
- User must have credit evaluation permission
- Farmer must exist
- Evaluation type must be valid
