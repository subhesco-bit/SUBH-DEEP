# API-059: POST /api/v1/group-buying/join

**Phase:** 4.3 (Optional Routes)

**Priority:** P2 - Medium  
**Status:** Specification Complete  

## Endpoint Specification

### Method & Path
```
POST /api/v1/group-buying/join
```

### Purpose
Join an existing group buying initiative. Allows farmers to commit to purchasing at group pricing.

### Service Dependency
- `backend/src/services/legacy/buyingClubService.js`
- Method: "joinGroupBuying(groupBuyingId, participantData)"

## Request Specification

### Headers
```
Authorization: Bearer {access_token}
Content-Type: application/json
```

### Body Schema
```json
{
  "group_buying_id": "uuid (required)",
  "participant_id": "uuid (required)",
  "committed_quantity": "number (required, > 0)",
  "contact_preference": "string (optional, enum: email, phone, platform, default: platform)",
  "special_requests": "string (optional)",
  "terms_accepted": "boolean (required, must be true)"
}
```

### Validation Rules
- User must be authenticated
- User must have group buying participation permission
- Group buying must exist and be recruiting
- Participant cannot be organizer
- Committed quantity must be positive
- Terms must be accepted
