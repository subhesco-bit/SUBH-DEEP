💡 Key Principles

📘 Git is Truth

Not email, Slack, or files. All changes flow through git commits.

⏱️ Frequent Commits

Devin: every 15-30 mins. VS Code: on save. Claude: after review.

🤝 Explicit Handoffs

.ai/handoffs/ files are your communication medium between tools.

🎯 Clear Roles

Each tool knows exactly what to do and when to do it.

📝 Documented Decisions

.ai/decisions/ and .ai/reviews/ capture the reasoning.

✅ Zero Duplication

Single source of truth in git prevents version conflicts.

📅 Typical Day

8:00 AM - Devin: Read tasks → Create branch → Code → Commit → Push

10:00 AM - VS Code User: Pull → Test locally → Fix issues → Push review

1:00 PM - Claude AI: Review code → Document findings → Approve merge

3:00 PM - All: Merge to main → Feature is live! 🎉

Catch issues before committing. Run on save automatically.

❓ Common Issues & Fixes

📦 Branch doesn't sync

Run: git fetch origin then git pull

🔗 Merge conflict

See GIT_WORKFLOW_COMMANDS.md → Emergency Procedures section

📝 Forgot to push

Run: git push to sync your work immediately

🚫 Permission denied

SSH key issue. Run: ssh -T git@github.com
