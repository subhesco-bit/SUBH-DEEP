PHASE 12B-1 SAFETY POLICY

ROOT_MAIN ONLY.

NO:
- delete
- move
- rename
- copy between projects
- source modification
- auto-mount
- auto-fix
- git checkout/switch/reset/clean/merge/rebase/cherry-pick
- npm install/update
- database migration
- generator execution
- project merge

Parallel projects remain independent.

A missing static link is evidence for review, NOT permission to generate
a replacement file.

Dynamic resolution that cannot be proven statically is classified
UNRESOLVED_DYNAMIC, not MISSING.

Template/test/archive/generated files are preserved but separated from
production-runtime conclusions.
