# AFRERA Clone Completion Architecture

The clone treats AFRERA as a governed economic operating system. Its first deliverable is an executable source of truth that separates concepts, candidate files and verified runtime behavior. This prevents documentation volume or file existence from being mistaken for completion.

## Historical implementation baseline

This work continues the existing ChatGPT implementation rather than starting a parallel project. The inherited ChatGPT consolidation line ends at commit `054ddb120f51a08bee5c9d2ac439e5ee1a072e7e`. Git ancestry verification shows that `consolidated/final` contains every commit from `codex/chatgpt-tree-consolidation` and adds 22 later commits. The earlier `chatgpt-clone/foundation`, `chatgpt-clone/ai-erp-enhancement`, `chatgpt-clone/highest-standard-enhancement` and `chatgpt-clone/main-reconciliation-phase-1` branches are therefore implementation sources for the current baseline, not abandoned parallel concepts.

## Evidence rule

A capability is complete only after source, runtime, persistence, authorization, contract, journey, test and telemetry gates carry reproducible evidence. Candidate paths produced by the audit are starting points for investigation. They are never automatic proof.

## Maturity order

Work proceeds through concept reconciliation, industry baseline, sector journeys, intelligent assistance, connected system intelligence, bounded autonomy and futuristic capabilities. A later stage may be designed early, but it cannot be certified while its prerequisite gates are open.

## Workflow standard

Consequential workflows are state machines. Each contract defines actors, valid transitions, approval boundaries, timeouts, retry policy, compensating actions, audit events and acceptance criteria. CRUD endpoints and screens may implement parts of a workflow but do not establish journey completion.

## Sensitive decisions

Religion, caste, health, psychology and similar sensitive characteristics cannot be silently inferred. Voluntary constraints require explicit purpose-bound consent. They cannot determine discriminatory price, credit, employment, insurance or service eligibility. High-impact decisions require evidence, explanation, appeal and human authority.

## Running the registry

From `EBDESIGN-CHATGPT-CLONE`, run `npm run check`. The audit inventories the parent AFRERA tree, generates `generated/concept-runtime-audit.json`, and builds `generated/TODO.md`. Validation rejects unknown statuses, broken capability dependencies and incomplete workflow contracts.
