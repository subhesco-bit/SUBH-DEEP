USAGE EXAMPLES
════════════════════════════════════════════════════════════════════════════

1️⃣ Crop Recommendation:
   POST /api/v1/ai-modules/process
   {
     "module": "agricultural",
     "capability": "crop_recommendation",
     "data": {"soil": "loamy", "climate": "tropical", "budget": 50000}
   }
   → Returns: Recommended crops with yield, water, pest analysis

2️⃣ Animal Diagnosis:
   POST /api/v1/ai-modules/process
   {
     "module": "veterinary",
     "capability": "animal_diagnosis",
     "data": {"animalType": "chicken", "symptoms": ["lethargy", "diarrhea"]}
   }
   → Returns: Diagnosis options, tests, treatment

3️⃣ Recipe Generation:
   POST /api/v1/ai-modules/process
   {
     "module": "chef",
     "capability": "recipe_generation",
     "data": {"ingredients": ["rice", "chicken"], "servings": 4}
   }
   → Returns: Complete recipe with instructions

4️⃣ Disease Analysis:
   POST /api/v1/ai-modules/process
   {
     "module": "disease_analyzer",
     "capability": "disease_identification",
     "data": {"plantType": "rice", "symptoms": ["yellow_spots"]}
   }
   → Returns: Disease, treatment, PLUS farmer support letter
