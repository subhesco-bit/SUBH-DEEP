====== TROUBLESHOOTING ======

Port in use?
  taskkill /F /IM node.exe

Backend won't start?
  1. Check PostgreSQL running
  2. Check backend/.env exists
  3. Check errors.js exists: backend/src/utils/errors.js

Frontend won't load?
  1. Clear node_modules: rm -r node_modules && npm install
  2. Restart: npm run dev

Routes not working?
  1. Make sure routes.js was edited
  2. Save the file
  3. Wait for hot-reload
  4. Hard refresh: Ctrl+Shift+R
