## Prioritized Gap List (top value for a rural NE India farmer economy)

Ordered by how foundational the gap is to the platform's stated purpose — farmer income protection, transparent logistics, and trustworthy finance — not by document emphasis.

1. **Fix the broken Seed Vault page** — `SeedVaultPage.jsx` calls three API methods that don't exist; this is a live bug, not just a gap, and the cheapest fix on this list.
2. **Full-Truck Window (LTL→FTL pooling)** — directly moves farmer income (freight is the single largest line item eating into the 60–65% farmer share claim); currently 0% built.
3. **Regulatory-safe custody/escrow event engine** — the append-only, hash-chained, per-leg-liability handoff model is the mechanism that makes the "farmer is never left holding cold-chain risk" promise credible; today's ledger/escrow code doesn't implement this specific liability-attribution chain.
4. **Glut Early-Warning (listing-concentration detector)** — a farmer-protection feature core to the platform's differentiation story; only a generic price-trend hint exists today.
5. **Bank Passport UI wired to the real eNWR backend** — the hard part (eNWR issuance) is done; the consent-gated UI that turns it into "lender-ready evidence" is the missing 20% that unlocks the whole banking value proposition.
6. **Rural-first multi-channel login (missed-call, IVR, assisted kiosk login)** — accessibility for the stated "illiterate farmer, no smartphone skills" user is core to reach, not a nice-to-have; only SMS/Voice OTP exist today.
7. **Return-Load Board** — low engineering cost relative to value (reuses existing logistics/vehicle data), directly reduces empty-backhaul waste.
8. **Semantic Entity Matcher / Varieties Explorer (vernacular alias search)** — the current Regional Variety Directory has the data; it lacks the alias/search layer that makes it usable by non-English-first farmers.
9. **TrackDart-style multi-key tracking** — small delta over the existing single-key tracking function, meaningful trust/UX improvement for buyers and farmers.
10. **Advanced Geofencing zone taxonomy + auto-triggered actions** (disease zone → auto-quarantine radius, warehouse geofence → auto gate/dispatch) — geofencing infrastructure already exists; this is an extension, not a rebuild.
11. **Rideshare safety features (women-only trips, live trip share, night-trip flagging)** — the ride CRUD backend is real; these are the specific features that make the "safety-first" framing genuine rather than cosmetic.
12. **Second-Use Equipment Exchange** — cheap to build (simple marketplace CRUD), directly reduces farmer capital cost.
13. **SMS command grammar (BUY/SELL/PRICE/TRACK)** — meaningful reach extension for feature-phone users without requiring the full Voice-First OS.
14. **Circular Economy waste-to-value tracking** — lower priority than the above; valuable for ESG/sustainability story but not core income protection.
15. **Gifting & Festival Economy** — consumer-revenue feature, not farmer-protection-critical; lowest priority of the list.
