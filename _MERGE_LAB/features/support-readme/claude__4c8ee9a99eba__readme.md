# afrera-web Module

## Overview

The `afrera-web` module is responsible for the public-facing website of the AFRERA project. This module serves as the digital experience platform, providing users with access to various resources, information, and services related to AFRERA.

## Features

- Corporate website showcasing AFRERA's mission and services.
- Product showcase highlighting available offerings.
- Government schemes portal for relevant information.
- Farmer knowledge portal providing resources and guidance.
- Marketplace catalog for products and services.
- Investor and CSR portals for stakeholder engagement.
- Interactive maps and public dashboards for data visualization.
- API documentation and developer portal for integration.

## Technology Stack

The `afrera-web` module is built using the following technologies:

- **Next.js**: A React framework for server-side rendering and static site generation.
- **TypeScript**: A typed superset of JavaScript for improved development experience.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **shadcn/ui**: A component library for building user interfaces.
- **Cloudflare Pages**: A platform for deploying static sites.

## Getting Started

To get started with the `afrera-web` module, follow these steps:

1. **Clone the Repository**:
   ```
   git clone https://github.com/your-username/afrera.git
   cd afrera/afrera-web
   ```

2. **Install Dependencies**:
   ```
   npm install
   ```

3. **Run the Development Server**:
   ```
   npm run dev
   ```

4. **Open Your Browser**:
   Navigate to `http://localhost:3000` to view the application.

## Deployment

For deployment, the `afrera-web` module is hosted on Cloudflare Pages. Ensure that you have configured your deployment settings in the Cloudflare dashboard.
