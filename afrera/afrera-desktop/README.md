# AFRERA Desktop Application

The AFRERA Desktop Application is designed for power users and operational centers, providing a robust interface for managing various functionalities related to the AFRERA platform. This application supports offline operations and integrates with hardware devices to enhance user experience and operational efficiency.

## Features

- **Offline Operation**: Allows users to work without an internet connection.
- **Hardware Integration**: Supports integration with barcode scanners, QR scanners, receipt printers, and label printers.
- **Bulk Operations**: Facilitates large-scale data entry and processing.
- **Large-Screen Dashboards**: Optimized for display on large screens and multiple monitors.
- **File System Access**: Enables access to the local file system for data management.
- **High-Volume Data Entry**: Streamlined interface for entering large amounts of data efficiently.

## Technology Stack

- **Electron**: Framework for building cross-platform desktop applications.
- **React**: JavaScript library for building user interfaces.
- **TypeScript**: A typed superset of JavaScript that compiles to plain JavaScript.
- **Tailwind CSS**: A utility-first CSS framework for styling.

## Installation

To set up the AFRERA Desktop Application, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/afrera-desktop.git
   ```

2. Navigate to the project directory:
   ```
   cd afrera-desktop
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Run the application:
   ```
   npm start
   ```

## Development

For development purposes, you can run the application in development mode:

```
npm run dev
```

This will start the application with hot reloading enabled, allowing you to see changes in real-time.
