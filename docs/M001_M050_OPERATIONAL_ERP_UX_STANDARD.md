# M001-M050 Operational ERP + UX Standard

This clone-only layer makes ERP operations, pages, workflow, decision-making, middleware, visualization and user experience co-equal with AI.

Every M001-M050 module keeps its authoritative existing domain page/service/controller/database implementation. The operational workspace augments—not replaces—it with role-aware navigation, KPIs, workflow/state visibility, visualization contracts, decision centre, ERP controls, evidence/audit and production-readiness context.

Certification requires: real domain API data; no fabricated KPI/visualization values; role/geography authorization; validation; state-machine rules; maker-checker where consequential; transaction/idempotency controls; loading/empty/error/success UX; accessibility; responsive/mobile operation; multilingual support; audit/evidence; real workflow tests.

AI is a governed decision-support capability inside the ERP workspace, not the ERP itself.
